# Эко-сервис — веб-сервис формирования экологической культуры обучающихся

Учебный проект (ВКР, 38.03.05 «Бизнес-информатика», Московский университет имени С. Ю. Витте).
Сервис объединяет электронное обучение, личный эко-дневник студента, запись на экологические
мероприятия с контролем мест, автоматическое начисление достижений и отчётность для НОЦУР.

**Сайт:** _ссылка будет добавлена после размещения на хостинге_  
**Репозиторий:** https://github.com/vvbasov/ecoservice  
**Автор:** Басов В. В.

## Технологии

| Компонент | Версия |
|---|---|
| PHP (расширения pdo_pgsql, mbstring, zip) | 8.3 |
| PostgreSQL | 16 |
| HTML5 / CSS3 (без фреймворков и CMS) | — |
| Apache 2.4 (или встроенный сервер PHP для разработки) | — |

Сторонние библиотеки не используются: выгрузка `.docx`/`.xlsx` выполняется через `ZipArchive`
и шаблоны Office Open XML из каталога `templates/`.

## Структура репозитория

```
public/            корневой каталог сайта (страницы, стили, кабинеты)
public/teacher/    кабинет преподавателя
public/admin/      панель администратора
includes/          общие модули: db.php, auth.php, roles.php, badges.php, export.php, menu.php
sql/ecoservice.sql схема базы данных и тестовые данные (PostgreSQL 16)
templates/         шаблоны для выгрузки документов
uploads/materials/ загруженные учебные материалы (не хранятся в git)
exports/           временные файлы выгрузок (не хранятся в git)
```

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/vvbasov/ecoservice.git && cd ecoservice
   ```
2. Создать базу данных и импортировать схему с тестовыми данными:
   ```bash
   createdb -U postgres -E UTF8 ecoservice
   psql -U postgres -d ecoservice -f sql/ecoservice.sql
   ```
3. Настроить подключение одним из способов:
   * скопировать `includes/config.sample.php` в `includes/config.php` и указать параметры;
   * или задать переменные окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`
     (либо одну `DATABASE_URL=postgres://user:pass@host:5432/ecoservice`), а также
     `BASE_URL`, `APP_AUTHOR`, `API_TOKEN`.
4. Разрешить запись в `uploads/` и `exports/`.
5. Запустить для разработки:
   ```bash
   php -S 0.0.0.0:8080 -t public
   ```
   и открыть http://localhost:8080. Для Apache корневым каталогом сайта должен быть `public/`.

### Запуск в Docker

```bash
docker build -t ecoservice .
docker run -p 8080:80 -e DATABASE_URL=postgres://user:pass@host:5432/ecoservice ecoservice
```

## Основные сценарии использования

**Гость:** просмотр 16 открытых разделов (главная, о проекте, курсы, события, новости,
библиотека, эко-карта, инициативы, эко-привычки, раздельный сбор, энергосбережение,
достижения, контакты, справка, регистрация, вход), отправка обращения через форму обратной связи.

**Студент:** запись на курсы и изучение материалов; эко-дневник (вид действия из справочника,
значение, заметка); запись на мероприятия с контролем свободных мест; достижения; отчёты;
профиль со сменой пароля.

**Преподаватель:** создание и редактирование курсов, разделов и материалов (ссылки, файлы,
видео); публикация мероприятий; просмотр активности студентов; выгрузка отчётов в `.docx`/`.xlsx`.

**Администратор:** панель `public/admin/` — обзор, пользователи и роли (смена роли, сброс
пароля, удаление), обращения, справочники бейджей и видов действий, контроль регистраций
на мероприятия; все функции преподавателя.

## Полезные команды

```bash
php -l public/index.php                       # проверка синтаксиса файла
psql -U postgres -d ecoservice -c '\dt'       # список таблиц
pg_dump -U postgres -Fc ecoservice > backup.dump   # резервная копия
pg_restore -U postgres -d ecoservice -c backup.dump # восстановление
```
